# LevelUp Gaming

Proyecto frontend académico para Evaluación 1.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3 por CDN
- Bootstrap Icons 1.11.3

## Estructura
La tienda pública y el panel administrativo están separados en sus respectivas páginas.
El proyecto incluye carrito con localStorage, validaciones y alerta de stock crítico.
